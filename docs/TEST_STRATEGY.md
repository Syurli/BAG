# 测试策略

## 测试金字塔

- 单元测试：Schema、命令、坐标、时间和序列化；
- 契约测试：Bridge 请求、响应和错误语义；
- Golden Test：同一输入在不同引擎的事件时刻与变换结果；
- 集成测试：保存、连接、预览、编译和运行；
- 人工体验：3D Gizmo、时间轴、动画同步和战斗可信度。

## 必测场景

Undo/Redo、稳定 Diff、断线重连、资源重命名、低帧率、高播放倍率、动画 Marker、Sweep、迁移失败、能力缺失和 LLM 无效 Patch。

## 完成定义

功能只有在代码、测试、文档、错误提示、回退路径和至少一个真实示例同时完成后，才视为 Done。
