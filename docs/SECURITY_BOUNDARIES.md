# 安全边界

## 信任区域

- 用户选择的 CrossLoom 项目目录；
- 已认证的本机 Bridge 会话；
- 经过 Schema 校验的数据；
- 明确配置的 LLM Provider。

## 不可信输入

项目文件、第三方 Schema 扩展、Bridge 消息、LLM 输出、导入资源元数据和外部 URL 均按不可信处理。

## 强制要求

- 防止路径穿越与符号链接逃逸；
- 不执行数据内嵌脚本；
- 远程请求超时、限流并可取消；
- 密钥仅进入系统安全存储或环境变量；
- 日志默认脱敏；
- 远程 LLM 调用前显示将发送的数据范围；
- 最终资产写入必须由 Bridge 在引擎侧校验。
