# 百舸 CrossLoom

> **百舸争流，共织通途。**

CrossLoom is a local-first, cross-engine game authoring platform with human-controlled AI.

本仓库正在建立第一版工程基础。项目目标是以统一领域数据、引擎桥接插件和受控 LLM Patch 工作流，为独立开发者与中小团队提供易用、廉价、可迁移的游戏内容编辑工具。

## Status

- Version: `0.1.0-foundation`
- Stage: architecture and infrastructure bootstrap
- Primary engine: Unreal Engine
- Reference engine: Godot
- Experimental engine: Unity

完整工程结构、设计原则、AI 开发约束和产品网站将在本次初始化提交中补齐。
