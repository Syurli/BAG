01

DESIGN PRINCIPLES

工具应当服务创作者，而不是接管创作。

Tools should serve creators, not take over creation.

Local-first

本地优先

Local by default

源数据、正式资产、Bridge 与 Runtime 默认在开发者设备中工作。网络与远程模型始终是显式选择。

Source data, production assets, bridges, and runtimes stay on the developer's machine by default. Network access and remote models are always explicit choices.

Engine-neutral

设计意图独立

Intent stays portable

CrossLoom IR 描述动画、判定、事件和状态等领域语义，不把创作内容锁在某个引擎的私有资产结构中。

CrossLoom IR describes animation, hit detection, events, and state semantics without binding authored content to a proprietary engine asset format.

Human-controlled

人工最终确认

Human approval

LLM 只提出经过 Schema 校验的 Patch。每项变更都可以比较、拒绝、撤销并记录批准链。

LLMs only propose schema-validated patches. Every change can be compared, rejected, reverted, and recorded in an approval trail.

Open & portable

开放且可迁移

Open and portable

开放 Schema、Bridge Protocol 和参考 Runtime；即使不再使用 Studio，项目数据仍可被读取与维护。

Schemas, the Bridge Protocol, and reference runtimes remain open, so project data can still be read and maintained without CrossLoom Studio.
